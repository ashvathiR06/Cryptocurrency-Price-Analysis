# Cryptocurrency-Price-Analysis
Analyzed historical cryptocurrency price data to identify price trends, daily returns, and volatility using Python. Created visualizations for price movement and comparative performance of selected cryptocurrencies.

# Stock-Market-Data-Analysis

Retrieved and analyzed historical stock market data using Python and the `yfinance` library. Extracted key market indicators including **Open, High, Low, and Close (OHLC) prices** for selected stocks. This project demonstrates the use of **Python and Pandas for financial data retrieval and analysis**.
